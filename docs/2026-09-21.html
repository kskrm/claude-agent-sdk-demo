答えを一瞬で出す新AI登場

Hacker News・9/16・原題: Introducing System One Models and Jev

TypeSafe AIという会社が、文章を一文字ずつ書くのではなく、答えをまるごと一瞬で出す新しいタイプのAI「Jev」を公開しました。答えが返ってくるまでの時間は最短0.07秒、最長でも0.5秒と、これまでのAIより最大200倍速いとされています。しかも、事実と違うことを答えてしまう問題が起きない仕組みになっているといいます。

そもそもの話

これまでのAI（ChatGPTなど）は、文章を単語ごとに一つずつ予測しながら答えを作る仕組みです。そのため長い答えほど時間がかかり、時には事実と違う内容をもっともらしく答えてしまう「ハルシネーション」という問題もありました。今回登場したのは、この仕組みを根本から変える新しいタイプのAIです。

たとえるなら

これまでのAIは、注文を受けてから一文字ずつ手書きで返事を書く郵便局員のようなものでした。新しいSystem Oneモデルは、あらかじめ用意された回答カードの中から、いちばん当てはまるものを一瞬で選んで渡す窓口係のようなイメージです。書く手間がかからない分、圧倒的に速く答えを渡せます。

数値や選択肢など、答えの形式をあらかじめ決めておくことで、想定外の形のミスが起きないようにする考え方です。プログラムが安心して結果を使えます。

確率のキャリブレーション（RLCD）答えの自信度を正しい確率で示すよう訓練する方法

一般利用者リアルタイム性が求められるアプリの応答が速くなり、AIが誤った内容を答えてしまう被害を受けにくくなると期待されます。

AIの起動待ち時間が一定に短縮

AWS Machine Learning Blog・9/19・原題: The new AgentCore runtime: Elastic, optimized, and consistently fast starts

AWSが、AIエージェント（人の代わりに目的達成まで自分で考えて動くプログラム）を動かす裏方の仕組みを新しくしました。これまでは扱うデータの量が多いほど起動に時間がかかっていましたが、新方式では量に関係なく約2秒で起動するようになりました。本番で多数のエージェントを動かす企業にとって、待ち時間の予測がしやすくなります。

エージェントの裏方とは

AIエージェントは、使う人がいない間はコンピューターを止めておき、必要なときだけ立ち上げる仕組みで動いています。この立ち上げには準備時間がかかり、これを「コールドスタート（電源を入れてから使えるようになるまでの待ち時間）」と呼びます。AWSはこの立ち上げを管理する土台を「AgentCoreランタイム」として提供しており、今回この仕組みが新しくなりました。

たとえるなら引っ越し準備

引っ越しのたびに荷物の量に合わせて新居を一から掃除し家具を配置していたら、荷物が多いほど時間がかかります。新しい仕組みは、あらかじめ用意しておいた「モデルルーム」をそのまま複製して住み始めるようなもので、荷物の量に関係なくすぐに生活を始められます。

エージェントを動かすには裏側でコンピューターを用意し続ける必要がありますが、企業自身がそれを構築・保守しなくて済むように、AWSがまるごと管理してくれる土台です。今回この土台の仕組みが刷新されました。

コールドスタート止まっていたシステムを使い始める最初の待ち時間

使われていない間は電気代やコストを抑えるためコンピューターを止めておき、必要になったときだけ起動します。この起動にかかる待ち時間が長いと、利用者は最初の応答を待たされてしまいます。

スナップショット復元準備済みの状態を写真のように保存し、コピーして使う方式

エージェントの初期設定を毎回一からやり直すのではなく、一度準備が終わった状態を保存しておき、必要なときにその状態を複製して復元します。これにより扱うデータの量に関係なく同じ速さで起動できます。

メモリのページング使わなくなった分だけこまめにメモリを返す仕組み

これまではエージェントが使い終わるまで、必要な最大量のメモリ（作業スペース）を確保したままにしていました。新しい仕組みでは、必要な分だけ使い、不要になった分はすぐに返すため、無駄が減ります。

アプリ開発者エージェントの構成を大きくしても起動が遅くならないため、機能を増やすことに集中できます。
情報システム部門使わない分のメモリをすぐ手放す仕組みにより、多数のエージェントを動かしてもコスト効率が上がります。
一般利用者チャットボットなどエージェント機能を使うときの最初の待ち時間が、混み具合に関係なく安定します。

生命科学研究者向けAIの制限を緩和

Anthropic News・9/17・原題: Introducing the Life Sciences Verification Program

Anthropicは、生命科学の研究者向けに、審査に通ればAIの安全のための制限を一部外して使える新しい仕組みを始めました。対象は大学やスタートアップ、製薬会社などで、通常の利用は1年ごと、特に慎重な扱いが必要な利用は半年ごとに審査をやり直します。すでに数十の組織が試験的に利用を始めています。

AIの安全装置とは

AIには危険な使い方を防ぐための安全装置（セーフガード）が組み込まれています。たとえば病原体の作り方や毒性の強い化学物質の合成方法など、生物兵器につながりかねない質問には答えないよう制限されています。この制限は一般利用者を守る一方で、正規の研究者が新薬開発などの正当な研究をする際にも同じ制限がかかってしまうという課題がありました。

図書館の特別閲覧室

多くの図書館には、貴重な資料や取り扱いに注意が必要な資料を保管する特別閲覧室があります。誰でも入れるわけではなく、身分を確認され、利用目的を審査されてはじめて司書が鍵を貸してくれます。今回の仕組みも同じで、審査に通った研究者だけが、通常は閲覧できない資料に近い『制限を外したAI』を使えるようになります。

使われている技術
セーフガードAIが危険な使い方を拒否する安全装置

AIが病原体の作り方など、悪用されると人に危害を与えかねない質問に答えてしまわないように設けられた制限のことです。安全のためですが、正規の研究者が正当な研究をする際にも同じ制限がかかってしまうことがあり、今回のプログラムはその課題への対応です。

審査制度（Verification Program）資格を確認してから特別な許可を出す仕組み

研究資格やセキュリティ体制、倫理面での研究監督などをAnthropicが確認したうえで、通常より制限の少ないAIの利用を許可する制度です。誰でも使えるわけではなく、審査に通った組織だけが対象になります。

モデル会話や作業をするAI本体のこと

今回のプログラムでは、Mythos・Opus・Sonnetという3種類のAIモデルが利用できます。モデルによって得意なことや性能が異なり、研究内容に応じて選べるようになっています。

何が変わる？
製薬企業の研究者審査を通れば、薬の候補探索や臨床開発に関する質問でも、通常はブロックされる内容までAIに相談できるようになります。
